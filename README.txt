Lunarix is a simple x86 operating system mostlty for experimentation and learning.
Maybe one day I'll be serious about it, but I'll just use it to experiment any ideas or to learn a concept.

Only supports x86 and boots through legacy BIOS.

Credit to nanobyte's "Building an OS" series on youtube, and osdev.org wiki!

Build using 'make' and emulate using 'make run'.

Requires make, and NASM to build.
